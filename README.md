ChantierPulse — exemplaire AVEC connexion
=========================================
Comptes personnels, rôles (chef de chantier / conducteur de travaux / direction) et données partagées dans Supabase.

1. Exécutez supabase/schema.sql dans Supabase (voir GUIDE-DEPLOIEMENT.md, étape 1).
2. Ouvrez config.js et renseignez SUPABASE_URL et SUPABASE_ANON_KEY (et API_URL si vous utilisez le serveur Python).
3. Déployez CE dossier sur Vercel (voir GUIDE-DEPLOIEMENT.md, étape 3).

Ne mettez jamais la clé « service_role » dans ce dossier.
